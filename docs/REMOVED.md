文言も埋め込みだった。

**なぜ消したか**: **どこからも参照されていなかった。** 実際の再設定は `index.html` の

**戻すとしたら**: 戻す理由は無い。再設定を独立ページにしたくなった場合でも、
i18n（`data-i18n`）に対応させる必要があるので、書き直した方が早い。
